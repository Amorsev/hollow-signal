# Changelog

## 1.0.0 — first release (Minecraft 1.21.1, NeoForge 21.1.x)

- Horror director with 5 stages, personal and world dread, intensity setting, per-event toggles.
- Traces: torch theft, signs, chest gifts, tunnels.
- Entities: Listener (stalk / glance / creep / mimic), Watcher, Reporter, Hollow.
- Fake player in chat: join/leave, Tab list entry, 30+ dialogue topics (EN/RU), relationship, cursed-glyph replies.
- Glitches: screen interference + static, fog, HUD flicker, slowed sounds, phantom sounds, fake loading / disconnect / Windows 10-style error screens.
- Old-style main menu, optional classic textures (Programmer Art).
- Finale dimension *the_static* with receivers, core and three endings (Released / Loop / Record Erased).
- Multiplayer: split reality, mimic, fake leave, chat echo, co-op finale, group balancing.
- SAFE by default; opt-in HARDCORE fourth-wall mode with warning screen: real dialogs, notes in user folders (logged, safe cleanup), real crash after saving, separate opt-in cancellable PC shutdown, window title.
- Original textures and sounds; in-game automated tests (`gradlew runGameTestServer`).
